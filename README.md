# BoostLab

Guias e scripts transparentes para melhorar o desempenho do Windows, sem promessas de milagre.

- Site estático em um único arquivo (`index.html`): sem servidor, sem bibliotecas externas, sem cookies e sem coleta de dados.
- Os scripts `.bat` só são baixados quando a pessoa clica, e o código completo aparece na página antes disso, com o hash SHA-256.
- Nenhum script pede administrador, apaga arquivos, baixa algo da internet ou mexe no Registro, no Defender, no firewall ou no Windows Update.
- **Status:** os scripts ainda não foram executados em um Windows real. Leia o código antes de usar.

Para usar localmente, baixe `index.html` e abra no navegador.
